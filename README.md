# homelab mc-server modpack

MC 1.21.1 NeoForge 服务器的客户端同步清单，供 [Simple Mod Sync](https://modrinth.com/mod/simple-mod-sync) 使用。

## 玩家使用方法
1. 安装 Simple Mod Sync（NeoForge 1.21.1）
2. 启动游戏 → Simple Mod Sync → 粘贴链接：
   `https://raw.githubusercontent.com/E-R-Butch/homelab-mc-modpack/main/modpack.json`
3. Sync，完成后重启游戏即可进服

服务器更新 mod 后，清单会同步更新，玩家只需再次点 Sync。
